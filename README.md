## Base Lógica

We implement and host Odoo Enterprise for companies of any size and industry.

**Mission.** A complete Odoo for each company, fitted to how it works: native features first, our own modules only where Odoo has nothing, kept running and up to date by us.

**Vision.** To be a reference for Odoo: systems that grow with each company, built to the standards of Odoo and the OCA.

**Open source.** Our modules that extend community modules are public, under AGPL-3: [baselogica-open-addons](https://github.com/baselogica-ar/baselogica-open-addons).
